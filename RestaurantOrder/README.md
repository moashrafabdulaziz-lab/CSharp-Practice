
# Restaurant Order

A small C# console application for handling restaurant orders and calculating the final order total.

## Features

* Select menu items using an enum
* Calculate the total price of selected items
* Apply tax and service charges
* Validate user input
* Display order details and the final total

## C# Concepts Practiced

* Enums
* Methods
* `params`
* Loops
* `TryParse`
* Input validation
* Type casting
* Basic calculations

## Example

The application accepts menu items along with tax and service percentages, then calculates and displays the order total.
